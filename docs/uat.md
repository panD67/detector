# UAT Fase 12

## Skenario

1. Buka beranda dan navigasi dengan keyboard.
2. Tambah profil AI, test koneksi, dan set aktif.
3. Analisis link dengan URL valid dan mode seimbang.
4. Jalankan mode tempel manual saat proxy gagal.
5. Analisis 5.000 komentar dari file CSV.
6. Analisis foto JPG dengan OCR.
7. Simpan, buka, ekspor, dan impor riwayat.
8. Hapus semua data dan pastikan storage kosong.
9. Buka aplikasi pada lebar 360px dan 1440px.
10. Jalankan dengan provider key salah dan pastikan pesan jelas.

## Kriteria lulus

1. Tidak ada jalan buntu.
2. Tidak ada crash.
3. Semua alur bisa diselesaikan dengan keyboard.
4. Tidak ada kata terlarang atau em dash.
5. Lighthouse Accessibility minimal 0.95.
